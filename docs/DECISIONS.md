# Decisions

- **ADR-001 — RAVEN naming:** Research, Analysis, Verification & Enterprise Navigation.
- **ADR-002 — SQLite primary database:** fit-for-MVP embedded persistence and operational simplicity.
- **ADR-003 — Separate capabilities:** search, crawler, model, embedding, and MCP adapters are independently selectable.
- **ADR-004 — Brave primary search:** default discovery provider.
- **ADR-005 — Crawl4AI Local primary crawler:** Docker-backed local reading default.
- **ADR-006 — Crawl4AI Cloud fallback:** first managed crawling fallback.
- **ADR-007 — Exa first-class search + MCP:** semantic discovery and agent extension.
- **ADR-008 — Firecrawl first-class search/crawler/MCP:** robust independent cloud retrieval.
- **ADR-009 — Gemini primary model family:** configuration-driven fast and deep models.
- **ADR-010 — Deterministic Fast Research:** application code controls ordinary research sequencing.
- **ADR-011 — Agent Framework for Deep Research:** agentic behavior belongs to investigatory questions.
- **ADR-012 — RAG-first policy:** reuse held evidence before external work.
- **ADR-013 — Immutable/versioned profiles:** history is a product feature, not an audit afterthought.
- **ADR-014 — ResearchRun lifecycle:** research execution must be observable and reproducible.
