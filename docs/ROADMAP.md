# Roadmap

1. **Control plane (complete):** architecture, provider policy, decisions, runbook, and initial scaffold.
2. **Foundation:** Company CRUD, SQLite migrations, React API client, test harness, Crawl4AI health probe, Gemini adapter spike.
3. **Sacred vertical slice:** Company → Brave → Crawl4AI Local → Gemini → evidence-backed profile.
4. **Persistence and evidence:** ResearchRun, SourceDocument, profile versions, ProfileEvidence.
5. **Knowledge:** chunking, embeddings, CompanyId-filtered retrieval, Ask Company.
6. **Deep Research:** Agent Framework tools, RAG-first policy, Exa MCP; Firecrawl MCP if time permits.
7. **Provider expansion:** Exa, Crawl4AI Cloud, Firecrawl, settings and fallback orchestration.
8. **Tracking and hardening:** refresh, history, changes, retries, provider tests, demo preparation.
